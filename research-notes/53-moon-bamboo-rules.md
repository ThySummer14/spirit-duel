# 追月神、辉夜姬主要规则接入

2026-10-17。以`research-data/cards.json`的19700–19708、17600–17608基础牌文为本批版本，不再追溯全部赛季平衡调整。指定录像尚未逐卡覆盖本组，全部新增条目保留`verificationPending`。普通专项通过只证明本批实现满足已列条件，不代表全库还原。

追月神基础2/4、觉醒+1/+1。抽到追月神的牌才为存活且激活的追月神结附宵月，取得牌不触发。基础宵月仅在0鬼火时让追月神自己的牌获得瞬发；觉醒后覆盖己方其他式神的牌。使用符合条件的牌后移除实际灵咒，仍遵守全队每回合一次瞬发；不会在灵咒移除后继续显示旧瞬发。当前重复结附刷新同一个宵月，不实现无依据的多层储存。

| 追月神牌 | 实际结算 |
| --- | --- |
| 月海潮生，一勾 | 完整占卜2，可逐牌安排顶底；选择完毕后获得1鬼火。 |
| 满月，一勾 | 可选择任一存活式神，包括未激活者；移除当前实现的宵月、鸮之守护、蛊蚀，再恢复全部生命。保留神木庇佑等非灵咒能力。敌方帷幕仍限制选取。 |
| 邀月，一勾 | 按实际抽牌流程抽2张，抽到牌的灵咒与基础能力先结算，再选择一张实际手牌原实例置顶；保留该实例的增强与其他元数据。 |
| 月盈则亏，三勾 | 在每回合最开始、自然复活前保存双方气绝快照。按上个回合开始快照先消灭当时气绝而当前存活者，再复活当时未气绝而当前气绝者。 |
| 月食，二勾 | 主动使敌方失去1鬼火；对手回合鬼火实际变为1时，从手牌自动使用，检查真实费用、等级、存活与眩晕。用牌支付响应先于牌效果；普通出击支付响应先于进场和战斗。 |
| 觉醒·追月神，二勾 | +1/+1，扩大宵月瞬发的己方牌范围，保留真实抽到追月神牌的结附能力。 |
| 清辉月华，二勾 | 4/5，进场结附宵月。普通出击次数用尽后，任一合法己方式神可消耗实际宵月免费普通出击；眩晕、勾玉、战斗区替换等限制仍有效。 |
| 神无月之佑，三勾 | 5耐久，己方回合开始结附宵月。双方真正花费鬼火时清空该牌手余火；鬼火增减和回合重置不当作花费，不制造2→0之间虚构的1鬼火响应。 |

鬼火写入汇入`GameState._set_fire`，覆盖主动牌、自动响应、普通出击、复活支付及现有获得鬼火的角色。保留原有各来源上限与数值。新增响应帧参与同一结算栈；牌宣告及反制、鬼火响应、牌开始及效果分别结算。

辉夜姬基础1/5、觉醒+1/+1。五种幻境共用一个实际场上实体，耐久累加；觉醒前新能力覆盖原能力，觉醒后能力逐次累积，同名能力也可多次触发。独立的其他角色幻境继续存在。检视显示当前全部累积能力和真实耐久，增强记录按本局已召唤的五种不同ID计算。

| 辉夜姬牌 | 实际结算 |
| --- | --- |
| 燕子安贝，一勾，5耐久 | 自己回合结束恢复所有己方角色各1生命，其他己方幻境各+1耐久；自身耐久≥10时也在敌方回合结束触发。 |
| 火鼠裘，一勾，5耐久 | 敌方式神对己方牌手造成实际战斗伤害后反伤2；≥10时对己方式神造成实际战斗伤害后反伤1。零伤和非战斗伤害不触发；已经取得的反伤不因同次牌手伤害击破幻境而消失。共享交战结束反应队列。 |
| 五道难题，一勾 | 选择实际牌库中的一张辉夜姬幻境，原实例置入手牌并获得+5耐久；取得牌清除牌库灵咒，不当作抽牌。牌库当前包含五种不同幻境时获得瞬发；没有可检索牌时禁止使用。 |
| 佛前石钵，二勾，5耐久 | 己方回合结束且战斗区空时召唤0/5石钵；≥10时召唤4/5。石钵真正占据战斗区并触发进场，离开战斗区或气绝后移除，不进入普通式神的归队循环。 |
| 龙首之玉，二勾，5耐久 | 每个回合结束投射2，命中当前战斗区或空场牌手；≥10时再对敌方准备区式神各造成1伤害。 |
| 觉醒·辉夜姬，三勾 | +1/+1，允许幻境能力累加。此前已召唤五种不同幻境时，觉醒后实际召唤全部五种，各1耐久。五张同名不满足增强。 |
| 蓬莱玉枝，三勾，5耐久 | 每个回合开始抽1牌并获得1鬼火；≥10时依次结算两次独立的“抽1→获得1鬼火”，不用一个抽2替代。 |
| 竹取物语，三勾 | 5/5，每个回合结束随机实际召唤一种辉夜姬幻境。自身幻境≥20耐久时，将护甲、暴击、减伤后的伤害替换为幻境损失，单次最多失去5耐久，原伤害全部防止；跌破20后后续伤害正常。 |

选择UI和AI都处理真实实例ID，防止错玩家、失效ID和空检索池。AI满月优先己方受伤者，月盈则亏仅在快照有实际收益时使用。16张主体牌复制已有完整原版PNG，不裁切、不生成新外框；原版完整主体牌累计17位角色136张。没有找到石钵独立原版立绘，当前召唤物使用辉夜姬立绘占位，数值与行为独立。
