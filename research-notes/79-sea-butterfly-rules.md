## 来源与版本

主体采用`art-reference-official/卡面-按版本/17_鸣雷启蛰/287_灵海蝶/`九张完整PNG及[网易卡库](https://ssr.res.netease.com/pc/zt/20191112204330/js/index_4539655c.js)。本次抓取的九个定义与项目`research-data/cards.json`逐字段一致，见`official-source-evidence.json`；八张主体PNG逐字节同步并保存`card-art-manifest.json`。

[官方2023-03-15灵海蝶曝光](https://www.taptap.cn/moment/385126671985936324)的附图提供海灵的完整词条：不能叠加；遭敌方式神攻击时，随机眩晕该式神、使其获得2破甲或在本次战斗降低2力量，然后移除。原图已保存为本批`reveal.png`。该图的碧海之蝶是预览2/7；本地完整主体PNG与官网基础卡库均为2/6，本批采用2/6。没有逐赛季追查或改动之前已经明确接入的版本。

## 实际接入

| 卡牌/能力 | 结算与交互 |
| --- | --- |
| 基础2/5 | 灵海蝶真正进入战斗区时结附海灵；仍在原位置时不虚构移动事件。普通攻击、移动牌与复活后移动共用入场事件。 |
| 海灵 | 独立灵咒，唯一附着、气绝清除、源式神气绝后已附着灵咒仍可触发。眩晕走共用时限，破甲走共用获取与抵消，减攻只保存在当前交战帧中。连击只触发一次，减攻覆盖同一战斗各段；人面树生命替代战斗伤害不受力量降低影响。 |
| 波缀 | 先将灵海蝶移入战斗区，再使选中的活敌方式神激怒。进入战斗区不自动攻击；激怒产生真实出击约束。 |
| 灵巡 | 瞬发，选择己方式神结附海灵，然后占卜2。以真实牌库实例进行置顶/置底选择，AI也完成该选择。 |
| 碧海之蝶 | 2/6形态；附着于自身的海灵随机选择两项不同效果，只计一次海灵触发。 |
| 觉醒·灵海蝶 | 选择并移动己方式神，印刷+1/+1后替换基础能力。此后己方所有式神（含计作式神的召唤物）进入战斗区均结附海灵；重复结附投射2，遵守战斗区目标优先及来源是否存活。 |
| 迁溯 | 灵海蝶气绝时可用；选择己方式神，若气绝则真实复活，随后在准备区与战斗区间移动。本批按未写“气绝式神”的基础牌文允许存活目标执行移动，保留原客户端待核标记。 |
| 幽波之灵 | 5/7形态及共用追猎；攻击实际敌方式神时触发自身海灵。目标为牌手的被命令攻击不消耗海灵。沿用既有共用普通追猎目标范围，未修改其已建立的回归约束。 |
| 月珊瑚 | 可选择友方或敌方活式神，排除敌方帷幕与牌手；造成3+本局海灵触发次数的伤害，恢复己方牌手同量生命。法术伤害增减另走共用通道。手牌展示和自动施放均读取同一整局计数。 |
| 海心落 | 10耐久幻境；进场为选择的己方式神结附海灵，再命令该式神真正攻击且本次免疫战斗伤害，不消耗普通出击鬼火/次数。幻境在场使己方海灵同时执行三项效果且保留，幻境消失恢复正常触发后移除。 |

海灵的事件计数属于牌手，源式神气绝/复活不重置。攻击方幽波之灵与防守方海灵在防守响应查询前处理，已处理标记保存在可暂停的交战帧中；后续响应或连击不会重复抽随机结果。眩晕不取消已经宣布的本次攻击，但会阻止随后查询到的眩晕式神响应牌；已有攻击/眩晕框架及专项正反例共同覆盖此行为。

`sea_butterfly_rules.gd`负责角色能力，`game_state.gd`只接入入场事件、合法目标和交战减攻；UI显示真实灵咒状态、整局触发次数和当前月珊瑚数值，海灵结附及随机效果产生可见飘字。AI逐张实际使用八张牌。来源被移除/气绝、非攻击伤害、攻击牌手、重复觉醒、敌方帷幕等反例包含在专项中。
