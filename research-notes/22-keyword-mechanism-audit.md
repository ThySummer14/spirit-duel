# 关键词机制调查与执行器缺口（2026-10-08）

本轮重新搜索官方机制说明、平衡公告和原作者机制实测，并对照原始牌库与实际 GDScript 执行路径。目的不是让旧映射获得更像原版的名字，而是找出应由规则层承担的共同能力。本轮还原山童、白狼共16张牌并修复相关战斗底层；其余角色依然有大量未还原项目。

## 关键发现

旧词表把连引解释成“抽取同式神牌”、专注解释成“首张牌额外抽牌”、爆能解释成“全部能量转攻击”、烹饪解释成“集齐全体+1/+1”、起源解释成“洗回同名牌”。这些是本地历史映射，不是游戏规则。界面释义已经改正，相关未实现的选择、支付、永久物、卡牌生命周期不能因此算作完成。

原始快照的标签统计见 [keyword-inventory.json](../output/godot-combat-keywords-20261008/keyword-inventory.json)。其中贯通标签涉及45个本地可映射角色，追猎39个、迅捷55个、响应57个。此数字只说明共享基础设施值得优先修，不能拿来表示本轮修好了这些角色。快照存在漏标、过期牌文，不能以搜索词计数替代逐卡审查。

## 战斗、状态与费用

| 词条 | 实际作用与容易混淆之处 | 本地进展 |
| --- | --- | --- |
| 瞬发 | 首张有效瞬发消耗共享免火额度，和自然零费分开 | 已有支付与UI专项；敌方回合资料有冲突，见21号记录，未暗改既有规则 |
| 响应 | 符合具体触发事件时自动支付和使用；不等于任意手动打断 | 已核对角色使用自动响应；旧卡池仍有手动窗口映射 |
| 贯通 | 伤害溢出到牌手；式神自身屏障、免伤不能保护牌手 | 本轮共享战斗支持、山童/白狼接入；未核对的专属转换仍待查 |
| 穿刺 | 伤害前移除目标护甲和屏障 | 本轮加入；新起弓接入，区别于贯通 |
| 连击 | 普通交战前额外先造成一次伤害 | 本轮替换旧尾随补刀；逐段触发，配贯通可续打牌手 |
| 先攻 | 提前造成战斗伤害，防守方也能生效 | 本轮补防守先攻；与连击的基础组合有专项，特殊复活仍待查 |
| 远程 | 从准备区攻击，不进战斗区、不受战斗反击 | 本轮支持形态和临时能力，保留己方前线；不屏蔽响应 |
| 直击 / 追猎 | 前者直接攻击牌手；后者选择敌方式神 | 不可混成无条件自由选靶；全库尚未完成，追猎旧特殊牌有版本边界 |

| 必杀 | 实际造成伤害后消灭式神 | 2026-10-09 接入真实战斗必杀与夺命增强；护甲/屏障/伤害转化为0时不触发，法术必杀及全卡池仍未完成 |
| 吸血 | 伤害后恢复己方牌手生命 | 鸩条件吸血已有，通用法术/能力来源与替代效果仍待完成 |
| 帷幕 | 阻止敌方指向选择，不能挡范围或随机效果 | 通用选靶过滤尚未接入全卡池 |
| 迅捷 / 昂扬 | 分别减免普通出击的鬼火 / 次数 | 迅捷已有；2026-10-17 已补昂扬独立的一次出击状态与惠比寿升级来源，其余来源仍待逐牌还原，见 `44` |
| 不屈 | 生命大于1才可挡一次致命伤；生效后移除 | 已有一次、战斗限定、狂啸回合下限的独立表示 |
| 屏障 | 免疫一次伤害，优先于护甲结算 | 已有；本轮补穿刺移除、贯通独立、两段伤害交互 |
| 眩晕 | 限制出击及所属牌，通常不停止被动 | 已核对牌生效；旧卡中的限制仍非全覆盖 |
| 护甲 / 破甲 | 抵挡 / 追加伤害，具有回合寿命，施加时相抵 | 已有共享入口；未核对牌的旧护甲持续方式仍待修 |
| 激怒 | 约束可选攻击者，攻击后解除 | 尚未还原，不能变成攻击加成 |

## 资源、牌区与版本机制

| 词条 | 机制要点 | 当前缺口 |
| --- | --- | --- |
| 觉醒 | 替换基础能力，持久保留；新版可出现在不同牌型上 | 已核对经典觉醒按法术执行，不能强制全库都是同一牌型 |
| 增强 | 每张牌自己规定条件、计数域、持续方式 | 妖刀、酒吞、凤凰火、山童等已有；不能统一加攻 |
| 起源 | 在用牌前选对应原版牌，共用一张手牌 | 钢风已有真实二选一；更多角色待逐项接入 |
| 弹回 | 使用后回手，并失去该次弹回能力 | 不能误作式神移动；全库牌实例状态待审 |
| 倒计时 | 己方回合递减、归零触发重置，额外减少可提前触发 | 已有角色/形态计时；不能用统一幻境计时取代 |
| 运势 | 掷骰与阈值比较，奖励依牌文 | 基础骰子已有；强制点数、修改结果等角色能力仍待还原 |
| 充能 / 爆能 | 能量槽及定额能量支付，分别于鬼火 | 基础槽和支付已有；旧爆能数值映射需逐卡替换 |
| 鼓舞 | 累积效果，由下一次普通出击消费 | 基础攻/甲已有；其他效果和角色例外仍待还原 |
| 灵咒 | 结附在单位或卡牌上的独立效果 | 部分专属状态存在，通用来源/叠加/移除生命周期未完成 |
| 幻境 | 独立耐久永久物，随牌手受伤结算耐久 | 钢风已核对；多个幻境承伤顺序仍需审查 |
| 占卜 | 检视顶牌并决定顶/底和顺序 | 旧UI只让选一张置顶，完整排序与置底还未实现 |
| 化身 | 指定事件下概率触发，生成合法牌自动使用 | 旧单步映射仍在；随机池、限次、合法目标须补齐 |
| 融合 | 同式神融合永久物合并，继承能力及数值 | 旧加攻血映射不完整，缺永久物合并及能力继承 |
| 连引 | 展示候选牌，原牌/候选选一使用，另一张洗回 | 旧chain-draw不是连引；需要完整选择及牌区交易 |
| 烹饪 | 获取分品质食材、三份合成为佳肴 | 旧全体增益不合格；缺食材实例、合成和佳肴使用 |
| 入夜 | 阈值状态，不够阈值时改增加入夜值 | 旧回合预约不合格；须实现牌手累计值与阈值分支 |
| 蓄力 | 支付后暂存牌，后续按牌文时机释放 | 要保留选择、来源及释放时机，不能套通用倒计时 |
| 专注 | 用牌后仍有鬼火则再支付1点，触发额外效果 | 旧首牌抽牌映射不合格；需额外支付及替代支付 |
| 战力 | 下一场战斗的伤害加成；战后或下个己方回合开始移除 | 尚未独立建模；不能长期改力量 |
| 疾速 | 有出击次数且牌需鬼火时改付出击次数，瞬发优先 | 尚未独立建模；须与坚守共享次数规则 |
| 坚守 | 特殊出击次数与移入战斗区的行为有关 | 本轮找到官方疾速提及坚守，但完整细则仍需继续找原始演示，未臆造实现 |
| 启悟 | 临时以启悟区代替手牌，离开后保留未用启悟牌 | 尚未还原独立牌区与退出流程 |
| 赐能 | 选择支付能量额外使用，回手后失去该赐能能力 | 旧“强化”不是完整赐能；须补牌实例能力消耗与回手 |
| 协战 | 绑定两位式神的特殊牌和构筑规则 | 旧“他人出击后加成”与该机制无关；版本及构筑需继续核对 |

## 后续批次的验收顺序

优先补通用伤害和选靶：帷幕、必杀、吸血、暴击、直击/追猎；由使用这些能力的完整角色卡组验收。再补资源与次数：昂扬、战力、疾速、坚守、专注、充能/爆能。涉及选牌/牌区事务的连引、赐能、占卜完整排序、启悟单独形成批次；融合、灵咒、化身和烹饪需要独立状态生命周期。每批仍须结算、选择UI、AI、正反例与组合测试同时交付，未完成的全库审计继续失败。
