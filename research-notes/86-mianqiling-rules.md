# 面灵气：派系、轮回之面与逐段妒心

2026-10-30 完成本批 Godot 主要机制和交互验收，输出目录沿用任务开始日期 `output/godot-mianqiling-20261028/`。本批没有完成指定录像的逐牌核验，所有新增覆盖保留 `verificationPending`，不据此宣称全库还原。

采用 `art-reference-official/卡面-按版本/09_四相琉璃/208_面灵气/` 的 20800–20808 完整原 PNG。八张主体卡图与源图的对应及 SHA-256 记录在 [card-art-manifest.json](../output/godot-mianqiling-20261028/card-art-manifest.json)，[originals.jpg](../output/godot-mianqiling-20261028/originals.jpg) 用于逐牌目检。旧官网快照另存于 [official-source-evidence.json](../output/godot-mianqiling-20261028/official-source-evidence.json)，其中新生双面多抽一张、心生七面异派免战伤、自欺派系数乘二与当前采用 PNG 不同，不能混用。

[官方版主的面灵气解析](https://www.taptap.cn/moment/121029471275845061) 所附原图补足轮回之面四种状态和变派系效果；[reincarnation-detail.jpg](../output/godot-mianqiling-20261028/reincarnation-detail.jpg) 保存该图。本批只采用其中补充机制，轮回身材仍依当前完整 PNG 的 5/5，不混入早期解析的 6/6。[社区机制记录](https://www.taptap.cn/moment/467093870207830538) 补充了护甲、暴击之后计算面灵气增减伤，以及原始零伤仍能经面灵气能力形成伤害的观察；这属于辅助记录，并非原客户端全组合验证。

| 牌或能力 | 实际接入 |
| --- | --- |
| 基础能力 | 2/5。同派式神造成的伤害减一；对异派式神造成的伤害加一，不影响牌手伤害。 |
| 新生双面 | 瞬发，选择真实友方或敌方式神后，再从四派中选择改变其派系；没有额外抽牌。敌方帷幕、非式神和牌手不构成合法目标。 |
| 心生七面 | +1 战斗牌，按实际交战式神派系取得本次必杀或不屈。不屈需要生命大于一，必杀需要实际伤害；没有自行新增防御响应。 |
| 幻化万象 | 3/6 形态，入场后等待玩家选择自己的派系。 |
| 自欺 | 按全场存活式神的不同派系数加二，选一式神造成伤害；随后仍适用真实派系增减伤。 |
| 禁断之面 | 按己方存活式神的不同派系数实际抽牌，气绝式神不计数。 |
| 轮回之面 | 5/5，己方回合开始随机转为其他派系。红莲获得贯通，变派系时己方存活式神各加一力量；紫岩获得不屈并治疗自己和牌手各三；苍叶获得迅捷并对随机敌方式神造成二伤；青岚获得帷幕并对所有敌方式神各造成一伤。设置为当前派系不会伪造变化触发。 |
| 觉醒 | 玩家选择永久派系后，获得 +2/+2 并替换基础能力为同派入伤减半、异派出伤翻倍。后续普通变派系仍可暂时覆盖，气绝后恢复永久选择。 |
| 妒心 | 三段真实投射。每段重新统计与面灵气同派的存活式神，再投射并随机转为另一派系；前线气绝后，后续投射可命中牌手。每次变系可分别触发轮回之面。 |

派系数据独立于旧能力和形态定义，由 `faction_rules.gd` 读取 `godot/content/factions.json`。当前有 215 个独立身份的图标核对记录：红莲 53、紫岩 53、苍叶 56、青岚 53；每条保留完整图路径、SHA-256、匹配分数、坐标和人工目检说明。自动定位原始结果和偏移定位结果分别存于 `faction-raw.json`、`faction-slide.json`，最终对应为 [faction-evidence.json](../output/godot-mianqiling-20261028/faction-evidence.json)，三张 `faction-sheet-*.png` 供逐图核对。缺少独立图标的 35 个历史入口或衍生体明确保留未知，没有按名称或配色猜测，也没有关闭这些入口。

雷冢是替换身体，运行时沿用原式神 `id` 并保存 `susanooOriginal`，不能直接借原式神图标判派系。现有官方曝光只展示其 0/1 与效果文本，没有独立派系图标；社区记录虽明确称其为红莲，仍未达到本批采用的原卡／官方证据要求。故替换身体默认保留未知，玩家真实变系能力仍可为其设置派系；该边界继续待核验。

共享层把派系修正接到实际伤害预判和最终扣血的相同阶段，并用于贯通的溢出计算；原始零伤只有面灵气确实能形成正伤害时才通过，普通零伤不会消耗屏障，负数伤害在任何加护修改前拒绝。普通同时交战保存双方该次派系及能力快照，避免首段气绝清除临时派系后，让本应同时发生的反击丢失原能力。轮回的红莲成长有独立撤销账本，日和坊属性重置及入内雀替身同步清除账本，之后气绝不再重复扣除。

新 `verify_mianqiling.gd` 的 183 项纯规则检查通过，包含目标与拒绝支付、永久／临时变系、气绝恢复、派系正反例、护甲与暴击后的加成、真实零伤／负伤通道、普通同时交战、必杀／不屈、抽牌数量、轮回四态及真实出击、贯通、重置成长、三段投射和 AI 实际选牌及完成选择。双尺寸原生专项共 201 项通过，包含上述规则，并在 1280×800、1600×740 通过鼠标选敌、四种派系卡选择、轮回变系、实际状态检视与永久觉醒选择。结果见 [rules.log](../output/godot-mianqiling-20261028/rules.log) 和 [native-final.log](../output/godot-mianqiling-20261028/native-final.log)，截图位于该目录 `screenshots/`；已检查四选一界面与红莲贯通详情。
