# 判官、海坊主及消灭／治疗归属（2026-10-09）

本轮替换 Godot 中两位式神、16 张主体牌的旧映射，没有修改旧 JS 引擎，也没有删除角色或缩小卡池。规则数据由 `godot/content/verified_rules.json` 覆盖旧导出库。测试通过说明这些分支按当前核对方案执行，不代表全部卡池或所有冷门交互已还原。

## 来源与版本

判官基础力量按[官方 2020-01-20 维护公告](https://www.taptap.cn/moment/15229385627929568)改为 2；同一公告明确击杀牌手不应触发判官觉醒。较早的 3 力量资料不再沿用。`research-data/cards.json` 的 12200–12208 提供卡牌快照；[原作者判官逐卡说明](https://www.taptap.cn/moment/15216531541591782)用于核对双方战斗区限制、生死无常的两次消灭、无情在同一次交换中的计时及夺命条件。

海坊主采用 11700–11708 的公测牌文快照，并与[原作者公测点评](https://www.taptap.cn/moment/15227883832214628)交叉检查。[2019 年百科](https://www.taptap.cn/moment/15218541460456090)混有早期测试版灵能、巨浪及沧海之盾，不能直接照搬。水龙卷先获得 3 护甲再按护甲伤害、蹈海 4/9，依据[2021-08-26 公告转载](https://www.iyingdi.com/tz/post/5110863)及[同期维护全文转载](https://m.ali213.net/news/gl2108/681387.html)交叉核对；没有找到官网原页，来源明确标注转载。

[原作者 2023 关键词机制记录](https://www.taptap.cn/moment/467093870207830538)提供必杀的伤害前提、伤害转化及狂啸交互，也支持增强在手牌中更新的通常规则。该文属于玩家实测，不能替代指定录像中尚未出现的具体交互。

## 已替换的逻辑

| 范围 | 当前实际结算 |
| --- | --- |
| 判官基础／觉醒 | 有来源的式神消灭事件。基础限判官自身，觉醒扩展己方来源；每次对敌方牌手 1 伤并治疗己方牌手 1。判官气绝后不发动；牌手死亡不计入式神消灭。 |
| 墨笔夺魂、勾诀 | 墨笔减少 2 力量及 1 当前／最大生命，随气绝清除；勾诀只能选择敌方力量不超过 2 的存活式神，直接消灭。 |
| 死之宣告 | 可以指定双方存活式神。消灭直接进入气绝生命周期，不伪造大额伤害，也不触发伤害响应或被护甲、屏障、不屈抵挡。 |
| 生死无常、无情 | 主动使用及自动响应均要求双方战斗区有式神，先己方后敌方消灭。无情影响新气绝，不追溯既有计时；同次交换及同阶段互伤保留气绝加时快照。 |
| 断罪、夺命 | 保存本局己方消灭计数，手牌动态显示。断罪按使用时增强力量进入；夺命真实战斗必杀，13 次后可消灭受到其战斗伤害的牌手。只损耗护甲、屏障阻挡、0 伤和转化为破甲均不触发。 |
| 海坊主基础／觉醒 | 治疗分开记录来源、实际回复及过量。只将海坊主对己方造成的过量治疗转换为等量护甲；觉醒额外给予式神等量力量，牌手不获得力量。 |
| 治愈之水、祝福之水 | 前者可选择双方角色，按海坊主每 2 护甲提高 1 治疗；后者治疗己方牌手及全部存活式神。两者使用已有共享瞬发额度，治疗不会复活。 |
| 灵能、水龙卷 | 灵能按牌手实际回复量再次治疗自身。水龙卷先授予护甲并抵消破甲，再读取实际护甲造成伤害；手牌预估与结算一致。 |
| 蹈海、巨浪 | 蹈海按战斗伤害治疗己方牌手和其他式神；巨浪逐个结算敌方式神 2 伤后汇总伤害治疗自身。屏障与护甲分别生效，不凭目标数固定治疗。 |
| 沧海之盾 | 目标即时获得 2 护甲，另存独立的本回合战斗伤害后回复牌手能力。自动响应支付手牌和鬼火后续接原战斗；回合结束或气绝移除。 |

新增 `panguan_rules.gd`、`haifangzhu_rules.gd`。共用伤害和气绝入口记录消灭归属，旧被动伤害、形态倒计时及自身伤害显式传递真实来源，避免嵌套能力误归给外层判官牌。增强计数、墨笔和临时回复均为可序列化状态。AI 使用同一合法目标／条件查询，主动消灭优先敌方、治疗优先己方。

## 交互与可见状态

战斗卡片和详情共享 `BattleStatus.unit_view`，保留上轮白狼私有目标过滤。新增消灭进度、墨笔、无情、过量转换、灵能、蹈海及沧海之盾标记；临时能力过期后标记同步消失。状态图形为本地可读表达，尚未宣称与官方图案逐像素一致。

目标选择实际调用规则允许列表。勾诀不能通过 UI 指定高力量目标，死之宣告可以点击己方式神，治疗包含牌手；取消不扣牌／鬼火，双方空战斗区不能打生死无常。

## 仍待核对的边界

以下 5 张牌保留 `verificationPending`，不计为全部核对完成：

- 断罪：已使用的形态是否继续随之后的消灭增长，缺直接实机证据；当前按出牌时增强值入场。
- 灵能：牌手满生命及过量部分是否应回响到自身；当前只回响实际回复量。
- 蹈海：同归于尽时反击治疗与气绝后过量转换的先后；当前保留反击治疗，气绝后停用基础过量转换。
- 巨浪：过杀伤害计入治疗及群体伤害汇总后的治疗顺序；当前按护甲后伤害量汇总，包含过杀。
- 沧海之盾：授予其他式神的治疗能力的来源归属；当前归属受授予式神，不借用海坊主的过量转换。

法术必杀、复活／替身和跨新式神的特殊组合不在本轮已核对范围。其他旧角色和旧 JS 实现仍然存在简化项，全库还原检查继续严格失败。
