## 玉藻前

基础3/4。使用手牌外的牌后独立投射2点，觉醒后改为3点；投射读取当时实际前线，不与法术伤害合成一笔。永久法术伤害增强跨气绝保存；从手牌使用的三张一勾法术先按已有增强结算，再获得本局法伤+1。自动生成或复制使用不触发“从手牌使用”的增强。

| 卡牌 | 实际结算 |
| --- | --- |
| 灵击，一勾 | 选择敌方式神造成2+已有法伤的伤害，随后手牌使用时永久法伤+1。 |
| 狐火，一勾 | 投射3+已有法伤的伤害，随后按同样条件增强。 |
| 堕天，一勾 | 总计4+已有法伤，逐点随机分配给敌方角色；每点重新读取存活目标，法伤只加到总点数一次。 |
| 祈念，二勾 | 3/4，真实化身，只能自动使用一勾法术。 |
| 幽梦，二勾 | 5耐久真实幻境；每个玩家回合首次敌方式神气绝时，随机生成并使用一张一勾法术。 |
| 燃雪，二勾 | 实际远程攻击，然后随机生成并使用一张一勾法术；不替换为直接伤害。 |
| 觉醒·玉藻前，三勾 | +1/+1，手牌外用牌投射改3；己方结束时随机使用一张一勾法术。 |
| 九尾煌炎，三勾 | 3/7，采用更高化身概率，每回合最多两次。 |

回合结束拆为原有结束效果、眩晕递减、玉藻前结束施法、切换玩家。普通眩晕在此刻解除后可以施法，剩余眩晕仍禁止；结束施法若需要选择，先完成真实选择和后续结算再切换玩家。[第一手机制观察](https://www.taptap.cn/moment/467093870207830538)用于核对这一顺序，尚未以指定录像逐卡覆盖。

## 帝释天

基础2/5，基础化身仅生成恩赐。莲华为己方唯一灵咒，减1力量；重新结附移除己方旧莲华，气绝移除。诸善奉行的永久强化随当前及未来的己方莲华生效，不叠出多个同方标记。白藏主净化可移除实际敌方莲华并恢复对应力量。

| 卡牌 | 实际结算 |
| --- | --- |
| 恩赐，一勾 | 共享瞬发额度，选择敌方式神结附莲华；仅从手牌使用抽1。 |
| 圣洁之王，一勾 | 3/6，己方结束时对当前己方莲华的敌方式神造成2伤。 |
| 诸善奉行，一勾 | 实际结附莲华，本局己方莲华额外减1力量。 |
| 十善业道，二勾 | 未结附莲华时造成4伤，已结附时真正消灭，不以高额伤害近似。 |
| 觉醒·帝释天，三勾 | +2/+2，选择结附莲华；化身牌池扩展为三个普通法术。 |
| 理想国，二勾 | 5耐久真实幻境；带莲华的来源式神不能造成伤害，覆盖战斗、法术、能力、牌手与友方伤害。阻止发生在目标护甲消耗前，不禁止非伤害的消灭。施法者气绝不使幻境失效，耐久归零即恢复伤害。 |
| 仁慈之王，三勾 | 5/7，每个玩家回合一次，对已结附莲华的式神使用普通法术后真实获得1鬼火、抽1；首次恩赐新结附不倒算触发。 |
| 圣子，二勾 | 4/6，每个玩家回合一次，队友对敌方式神使用非觉醒法术后，保留原施法者真实复制法术并对莲华目标使用。保留AOE、抽牌及选择，不伪造伤害包；复制不递归，不继承弹回。重新结附圣子不能刷新本回合次数，新回合恢复一次。 |
