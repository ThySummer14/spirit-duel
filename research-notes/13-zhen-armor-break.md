## 实际实现

| 牌/能力 | 本轮行为 |
| --- | --- |
| 基础能力 | 独立倒计时 2，归零产生 2 破甲并重置。累计真实触发次数；气绝暂停，复活继续。 |
| 鸩羽 | 本次 +2 力量；发起攻击时目标有破甲才获得本次战斗免伤。目标的破甲随后被消耗，不会丢失已经满足的条件。 |
| 鸩羽苏生 | 先减自己的倒计时 2，并完整结算触发，再抽 1 张；不再额外施加固定破甲。 |
| 寂寥心象 | 4/6 形态；每个敌方式神在本回合第一次获得破甲时减 1 倒计时。牌手不满足条件，队友施加的破甲可触发。同一目标再次叠加、消耗后再叠加或替换形态不重置首次次数。 |
| 毒蚀 | 本次 +4 力量，将双方伤害转换为等量破甲；主动使用可打牌手。响应仅在对手回合、本人受击且满足存活/勾玉/眩晕/鬼火条件时触发，准备区被追猎也可以响应。响应修改原战斗的反击力量与转换规则，不额外攻击、不移动防守者。 |
| 觉醒·鸩 | 印刷 +1/0；计时仍为 2，增强由整局的基础能力历史增长，气绝和重复觉醒不抹掉历史。首次觉醒的精确顺序列为待核验。 |
| 碧羽散华 | 5/7 形态；只有鸩自身产生的破甲会转成伤害，目标无破甲时也生效。没有虚构进场全体破甲；队友的破甲不会被转换。转换伤害可以消耗目标已有破甲。 |
| 毒之华 | 没有固定攻击加成；实际造成战斗伤害后，按目标剩余生命的一半施加破甲。护甲全额吸收时不触发。奇数取整列为待核验。 |
| 致命诱惑 | 本次 +2 力量/+2 护甲；发起攻击时目标有破甲才吸血。扣除护甲后造成的伤害（包括引爆破甲）用于治疗牌手；只打掉护甲不会治疗。 |

`armor_break_rules.gd` 统一处理破甲取得、消耗、来源归属、转换和战斗条件。牌手与式神都有独立数值，在自己的回合开始清除，气绝清除式神破甲。真实正伤害合并破甲后抵扣护甲；零伤害不引爆；屏障阻止实际伤害时保留破甲。破甲与旧 `brittle` 状态没有混为一谈。

毒蚀响应通过结算 ID 关联原战斗，卡牌被魔音反制时不施加转换。关联通过 JSON 往返检查，不依赖共享字典引用。倒计时触发是能力而非法术，不另消耗鬼火。现有其他角色的破甲动作与被动进入同一通道，但其旧牌文和其他近似行为仍未因此变成已还原。

AI 能评估自身倒计时法术、破甲目标的免伤/吸血收益，以及有后续攻击时主动使用毒蚀。界面补充牌手破甲、形态能力与基础倒计时共存的详情、觉醒手牌历史计数，以及响应、免伤、转换和破甲数值反馈。妖琴师专属“当前曲目/大合奏”说明不再误套在鸩身上。
