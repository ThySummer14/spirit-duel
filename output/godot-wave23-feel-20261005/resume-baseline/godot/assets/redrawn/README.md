# 经典式神重绘 · 2026-10-05

使用内置 `image_gen`，参照本地 `art-reference-official/卡面/01_式神/` 的原版角色卡面重新绘制完整经典基础包的 29 位式神。第一批完成八位，本批补齐余下 21 位。原版卡面仅作为角色外貌与画风参考；本目录 PNG 为生成的无框插画。服饰、发型、武器和配色尽量贴近对应参考，纹样与纸感保持同一方向。原版素材不复制到 Godot。

`prompts.json` 保存第一批八张的完整提示词；`prompts-classic-completion.json` 保存本批 21 张的提示词、参考路径和输出路径，并记录用户指出茨木童子面部问题后的修正提示词与最终选择。茨木童子的运行资源已经采用修正版，旧版没有接入游戏。

`portraits.json` 只管理 Godot 的角色插画路径与裁切焦点。主城、名录、编组、卡牌和战场共用此映射。普通与觉醒状态使用同一张重绘，觉醒边框仍由 UI 绘制；本批没有独立觉醒插画或每张技能牌的插画。

新增重绘时添加 PNG 和角色 ID 对应映射即可，不需改动 JS 规则内容或导出脚本。缺少映射或纹理无法导入时回退到角色现有 SVG；现有 SVG 保留。其他资料包的 221 位角色仍使用原占位美术。

本批新增：白狼、茨木童子、雪童子、山童、跳跳弟弟、清姬、鸩、海坊主、一目连、书翁、觉、犬神、判官、以津真天、凤凰火、青坊主、青蛙瓷器、山兔、妖琴师、青行灯、座敷童子。每位一张 1024×1536 PNG，路径为 `classic/<角色 ID>.png`。
