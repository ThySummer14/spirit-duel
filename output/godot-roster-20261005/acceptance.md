# Godot 角色迁入验收 · 2026-10-05

本次范围是让项目已有角色完整进入 Godot 的选角、构筑与对战流程。迁入前 Godot JSON 已包含 250 个角色 / 2114 张卡，基础与觉醒肖像也已存在；实际主城快速对战仍固定使用最初的原创阵容，编组初屏也先展示原创角色，因此直接游玩时很难看见迁入的式神。本次没有新增官方式神或改写浏览器规则。

实际变更：

- 主城显示当前四人阵容，支持按资料包试用；首次启动用妖刀姬、酒吞童子、兵俑、大天狗，有效的旧阵容保留。切换阵容即时更新肖像与存档，「开始对弈」使用选中的角色与默认牌。自定义牌组继续从编组出战。
- 对手从完整角色池按本局种子选取，排除己方角色。同种子得到相同对手，不再固定目录头四名。
- 编组 / 式神录优先展示经典与资料片角色，明确显示筛选数量 / 全库 250 位；所有内容资料包自动进入筛选和试用入口，补上衍生式神入口。
- 内容导出同时同步 500 张基础 / 觉醒肖像；已有内容与资源字节一致时不会重复写入肖像。
- 角色与卡牌索引分开，修复 `fanqie`、`jinran-buye` 同名 ID 的卡牌覆盖角色定义的问题。
