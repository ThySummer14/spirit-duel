# 孟婆规则接续验收（2026-10-16）

本轮在Godot中替换孟婆基础／觉醒和8张主体牌的旧近似逻辑，实际接入移底、同名移除、抽后弃牌、合法牌名选择、增强阈值与迅捷。不将数据中去掉“简化”字样当作还原，也不把剩余卡池标为完成。

[忘忧的旋律实际操作演示](melody-choice.mp4)是1600×740、30FPS、约7.63秒的原生录制：出牌→选择敌方式神→选择当前等级允许的牌名→移除同名牌及牌库底2张。`capture_motion.gd`使用真实鼠标输入和规则结算，验证原牌库顶实例仍然保留。演示注入零鬼火、双方3勾／兵俑1勾、5张已知牌库等隔离状态，不改变正式开局规则。

## 实际修复

| 范围 | 行为 |
| --- | --- |
| 基础／觉醒 | 实际对敌方牌手正伤害移底1／5，完全护甲、己方伤害及其他来源不触发；觉醒印刷2/2，敌库≤12给予迅捷 |
| 孟婆汤／汤盆冲撞 | 敌方式神3伤后移底3；投射4/8伤实际命中牌手时再触发基础能力 |
| 意外之喜 | 基础1鬼火，敌库≤16瞬发；真实抽2后选择弃1，不能取消跳过弃牌 |
| 三张形态 | 真实4/5、5/7增强8/10并贯通、4/6；天降之物己方回合结束移双方底1，奈何桥头按实际使用移除使用方同名副本 |
| 忘忧的旋律 | 瞬发、基础1鬼火；公开式神目录两阶段选牌名，按被选式神等级过滤，真实同名移除后再移底2 |
| UI与AI | 手牌实际费用／增强动态更新；弃牌与牌名选择可完成、可序列化；AI合法处理选择；当前形态能力在检视中可读 |

移底不抽牌、不立即判定空库败北，不触发书翁空库抽牌替代。私有`removedCards`历史保留原实例，日志和浮字只显示数量；牌名候选不读取隐藏手牌／牌库。普通对战未混入“有个牌局”的奈何桥头专用底1版本。
