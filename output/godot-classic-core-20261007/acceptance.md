# 经典基础组三角色并行还原验收

2026-10-07。本轮继续用户要求的原版还原，主代理负责共享规则及整合，三个代理并行处理妖刀姬、酒吞童子、兵俑。范围为 24 张主体牌、妖刀万华 1 张皮肤与 3 个历史生成牌 ID，以及三个本体的基础/觉醒能力。独立衍生式神、其他资料包、旧 JavaScript 执行器不在本轮已修复范围。
