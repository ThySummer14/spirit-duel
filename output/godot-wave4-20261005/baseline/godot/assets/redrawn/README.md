# 式神重绘 · 2026-10-05

使用内置 `image_gen`，参照本地 `art-reference-official/卡面/01_式神/` 的原版角色卡面重新绘制经典基础包 29 位、第二资料包 9 位、第三资料包 19 位，共 57 位式神。原版卡面仅作为角色外貌与画风参考；本目录 PNG 为生成的无框插画。服饰、发型、武器和配色尽量贴近对应参考，纹样与纸感保持同一方向。原版素材不复制到 Godot。

`prompts.json` 保存第一批八张的完整提示词；`prompts-classic-completion.json` 保存本批 21 张的提示词、参考路径和输出路径，并记录用户指出茨木童子面部问题后的修正提示词与最终选择。茨木童子的运行资源已经采用修正版，旧版没有接入游戏。

`prompts-wave2-wave3.json` 保存后续 28 张的提示词、原版参考、生成结果与最终资源，包含镰鼬由猫形偏离重试的记录。每次重绘或重试只使用对应原版卡面作为图像输入；不将被拒绝的生成图作为新参考。最终 28 张与所选生成结果逐字节一致，按原版逐张复核后的特征记录见 [art-review.json](../../../output/godot-wave23-feel-20261005/art-review.json)。

`portraits.json` 只管理 Godot 的角色插画路径与裁切焦点。主城、名录、编组、卡牌和战场共用此映射。普通与觉醒状态使用同一张重绘，觉醒边框仍由 UI 绘制；本批没有独立觉醒插画或每张技能牌的插画。

新增重绘时添加 PNG 和角色 ID 对应映射即可，不需改动 JS 规则内容或导出脚本。缺少映射或纹理无法导入时回退到角色现有 SVG；现有 SVG 保留。余下 193 位角色仍使用原占位美术。
